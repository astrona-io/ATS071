# Contributing

Read CLAUDE.md before editing. Its shared prefix is copied from ATS015, while the custom portion describes ATS071: Certified Backstage Associate (CBA), Backstage Catalog (22%), part of ATP014.

Preserve IDs, weights and existing track registration. Develop self-contained explanations with mechanisms, examples, prerequisites and failure reasoning. Start each section with an introduction and end each module with its own Summary. Keep technical Markdown draft until review.

The reading-only rule was lifted on 2026-11-03. Labs, playgrounds, capstones and quizzes are in scope. Labs and playgrounds are built with static checks only (`astrona validate -c`, `bash -n`, YAML parsing) and stay UNTESTED until a maintainer runs them; do not claim executed results. Each section has a `quiz.yaml`, and `sections/final-domain-quiz.yaml` closes the course; preserve stable question identities and per-option feedback.

Use primary sources in SOURCES.md and record adaptation paths in AUTHORING.yaml. Run the preparation reading verifier and content-sync parser checks when changing structure. Review Markdown and questions for semantic correctness as well as structure.
