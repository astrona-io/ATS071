# Using annotations

This section covers using annotations. It develops annotation Contracts And External Identity Mapping through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Distinguish annotations from labels and core specification fields.
- Explain how a plugin interprets an annotation value.
- Diagnose incorrect integration mappings without treating metadata as permission.
