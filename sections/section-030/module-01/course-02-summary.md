# Summary

Annotations carry named metadata that plugins and processors interpret through specific contracts. Their keys and values must match the installed consumer's expectations, including the external identity they reference. Labels support classification, while kind-specific fields describe the core entity model. An annotation supplies neither a credential nor authorization. Correct API responses can still show the wrong system when the annotation maps to an unintended external identity.
