# Summary

Catalog ingestion turns discovered source data into published entities through fetching, validation, processing and relationship assembly. Each stage has different failure evidence. A source can be reachable while its entity is invalid, and a valid entity can have incorrect relationships. Processing errors describe the metadata pipeline; they do not automatically mean the represented service is down. Repair the authoritative input or responsible processing contract.
