# Working with manually registered entity locations

This section covers working with manually registered entity locations. It develops registered Locations, Source Access And Entity Lifecycle through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Explain a manually registered location as an ingestion input.
- Distinguish location removal from entity lifecycle and rediscovery.
- Diagnose registration, fetch and processing failures separately.
