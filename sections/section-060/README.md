# Working with automated ingestion

This section covers working with automated ingestion. It develops entity Providers, Discovery Scope And Repeatable Ingestion through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Explain entity providers and processors as distinct ingestion roles.
- Reason about scheduling, full and incremental updates.
- Identify ownership, filtering and credential risks in automated discovery.
