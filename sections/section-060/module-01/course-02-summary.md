# Summary

Automated ingestion uses providers and processors to discover and maintain catalog data from defined sources. Providers establish owned entity inputs, while processors interpret and enrich them. Scheduling and update semantics determine how changes and removals propagate. Discovery scope, credential permissions and identity ownership must be deliberate so automation adds accurate metadata without producing conflicting records, uncontrolled load or accidental deletion.
