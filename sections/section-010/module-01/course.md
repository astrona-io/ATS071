# Software Entities, Ownership And Discoverable Relationships

This module develops software Entities, Ownership And Discoverable Relationships. Use the explanations to connect intended behavior with responsible components and observable evidence.

## Learning Goals

- Explain the catalog as a model of software and organizational relationships.
- Distinguish entity identity from deployment identity.
- Reason about ownership, freshness and catalog usefulness.

## Before You Start

Examples illustrate declared relationships and reasoning. No execution environment is required or claimed.
