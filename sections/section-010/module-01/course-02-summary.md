# Summary

The catalog organizes software and organizational metadata into typed entities and relationships. Entity identity uses a kind, namespace and name rather than a browser title or deployment Pod identifier. Ownership and dependency relationships support discovery when their sources are maintained. The catalog describes software; it does not automatically prove runtime health or replace the external systems that own deployment and infrastructure state.
